# MyPortfolio

A modern, multi-page developer portfolio built with HTML, CSS and JavaScript.

Designed with a dark neon aesthetic, smooth animations, responsive layouts and a clean user interface.

## Preview

MyPortfolio showcases web development projects, technologies and services in a modern and interactive layout.

## Features

- Multi-page website architecture
- Modern Neon Dark design
- Animated gradient background effects
- Responsive layout for desktop and mobile devices
- Interactive navigation
- Smooth scroll animations
- Project showcase with GitHub links
- Dedicated services and contact pages

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the website in your browser.

No additional build tools or dependencies are required.
